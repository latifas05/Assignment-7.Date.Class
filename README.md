# Date Class Implementation in Java

## **Overview**
This project implements a `Date` class in Java to represent dates and perform various operations, including:

- Validating if a date is correct (considering leap years).
- Updating a date with validation.
- Getting the day of the week.
- Calculating the difference between two dates in days.
- Printing the date in a readable format.
- Sorting a list of Date objects using `Collections.sort()`.

## **Run the program:**
java Main

### **Key Features**
- Uses **LocalDate** for accurate date calculations.
- **Handles leap years** properly.
- Implements **Comparable** for sorting.
- **Error handling** for invalid dates.
